# Telegram-мост для DSH

[English](README.md) | Русский

Плагин для [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)
(DSH): у каждой сессии DSH появляется свой топик в форум-группе Telegram.
Сессию можно вести и из DSH, и из Telegram; обе стороны видят один и тот же
диалог.

- **Одна сессия — один топик.** Топик с именем `воркспейс · название сессии`
  создаётся, когда сессия начинает работу. Он переименовывается, когда DSH
  даёт сессии название, закрывается при архивации и открывается при
  восстановлении.
- **В обе стороны.** Сообщения, написанные в DSH, появляются в топике. Текст
  из топика попадает в сессию так же, как сообщение из поля ввода DSH.
- **Вывод агента.** Ответ стримится в одно сообщение, которое редактируется
  по мере генерации. Вызовы инструментов сворачиваются в один раскрываемый
  блок. В конце хода приходит `✅ Done` со звуком.
- **Сабагенты.** Сабагенты не создают топиков. Каждый виден одной строкой в
  топике родителя: «working, waiting for result ⏳», затем «done ✅»
  (или failed / cancelled).
- **Подтверждения и вопросы.** Запросы подтверждения и `ask_user_question`
  приходят с кнопками. Telegram и GUI DSH соревнуются: побеждает тот, кто
  ответил первым, а запрос на другой стороне снимается.
- **Команды, файлы, голосовые** — см. [Использование](#использование).

## Требования

- DeepSeek Harness с менеджером плагинов (desktop или `dsh web`).
- Бот Telegram от [@BotFather](https://t.me/BotFather).
- Супергруппа Telegram с включёнными **Topics** (темами).
- По желанию: `ffmpeg` для голосовых сообщений.

## Установка

1. В DSH откройте **Plugins → Add plugin** и введите:
   - `github:Nergous/codex-tg`, или
   - абсолютный путь к локальному клону, например `/home/me/projects/codex-tg`.
2. Нажмите **Enable now**, затем откройте **Plugins → Telegram bridge**.

У плагина нет сборки и зависимостей. После изменения кода хоста (`index.js`,
`lib/`) перезапустите DSH; `client.js` перезагружается в открытой странице.

## Настройка

1. **Токен бота.** Создайте бота в @BotFather (`/newbot`), вставьте токен на
   странице настроек и нажмите **Save token**. Токен хранится в credentials
   DSH (`DSH_TELEGRAM_BOT_TOKEN`), а не в файлах конфигурации. Переменная
   окружения с тем же именем тоже работает.
2. **Группа.** Создайте группу, в настройках включите **Topics**. Добавьте
   бота и сделайте его администратором с правами **Manage topics** и
   **Pin messages**.
3. **Привязка.** Нажмите **Get bind code** и в течение 10 минут отправьте в
   группу `/bind <код>`. Группа сохранится, а вы станете разрешённым
   пользователем. Чтобы писать в сессии могли другие, добавьте их Telegram id
   на странице настроек. Сообщения остальных игнорируются.
4. Нажмите **Test connection**: проверяются токен, группа, Topics и права бота.

Один бот может опрашивать только один процесс. Если одновременно запущены DSH
desktop и `dsh web` с этим плагином, Telegram ответит `409 Conflict`;
используйте что-то одно или второго бота.

## Использование

Пишите в топике сессии, чтобы говорить с ней. Сообщения встают в очередь за
текущим ходом, как в DSH. Сообщение, начинающееся с `!`, вместо этого
корректирует текущий ход (steer). Пока агент ждёт ответа на вопрос, ваше
следующее текстовое сообщение становится ответом.

Фото прикрепляются как изображения (если модель их принимает), документы —
как файлы. Голосовые расшифровываются и отправляются текстом; расшифровка
показывается в топике. Без расшифровщика прикрепляется аудиофайл.

Файлы, которые агент показывает инструментом `present`, отправляются в топик
документами.

### Команды в топике

| Команда | Что делает |
|---|---|
| `/stop` | Остановить текущий ход (очередь сохраняется). |
| `/status` | Воркспейс, состояние, модель, заполнение контекста, режим вывода. |
| `/diff` | `git diff --stat` каталога сессии, полный патч файлом. |
| `/compact` | Сжать диалог (когда сессия свободна). |
| `/model [имя]` | Показать модели кнопками или переключиться по имени. |
| `/verbosity full\|tools\|final` | Подробность вывода в этом топике. |
| `/mute`, `/unmute` | Приостановить или вернуть вывод агента в топик. Подтверждения и вопросы приходят всегда. |
| `/steer <текст>` | То же, что `!текст`. |
| `/help` | Список команд. |

Остальные команды DSH, например `/goal` или `/permission`, выполняются через
реестр команд DSH, как из поля ввода. Неизвестный текст со слэшем уходит в
сессию обычным сообщением.

### Команды в General

| Команда | Что делает |
|---|---|
| `/sessions` | Последние сессии со ссылками на их топики. |
| `/workspaces` | Воркспейсы DSH. |
| `/new <воркспейс> [текст]` | Новая сессия в воркспейсе (по имени или пути), по желанию с первым сообщением. |

## Параметры

Все параметры — на странице настроек плагина, применяются без перезапуска.

| Параметр | По умолчанию | Значение |
|---|---|---|
| Output detail | `tools` | `full`: блоки инструментов раскрыты. `tools`: свёрнуты. `final`: только последний ответ хода. |
| Stream answers live | вкл | Редактировать одно сообщение по мере генерации. |
| Notify when a turn ends | вкл | Строка `✅ Done` со звуком; всё остальное — без звука. |
| Mirror my DSH messages | вкл | Показывать в топике сообщения, написанные в DSH. |
| Pinned status card | вкл | Первое сообщение топика закреплено и обновляется. |
| Create topic | при первом сообщении | Или сразу при открытии сессии, или никогда автоматически. |
| When a session is archived | close | Закрыть, удалить или оставить топик. |
| Approvals / questions with buttons | вкл | Выкл — только в GUI DSH. |
| Transcribe voice messages | вкл | Команда расшифровки, если задана, иначе speech-to-text DSH, если установлен. |
| Transcription command | пусто | Команда оболочки; `{file}` — WAV 16 кГц моно. Пример: `whisper-cli -l ru -nt -f {file}`. |
| Steer prefix | `!` | Пусто — префикс выключен. |
| Messages per minute | 20 | Лимит Telegram на группу, общий для всех топиков. |

Speech-to-text DSH (`@deepseek-ai/dsh-experimental-voice-input-bundle`)
необязателен и не распознаёт русский; для русских голосовых задайте команду
расшифровки, например whisper.cpp.

## Безопасность

- Обслуживаются только привязанная группа и разрешённые id. Всё остальное,
  включая нажатия кнопок, игнорируется.
- Токен бота хранится в credentials DSH и не попадает в логи, ошибки,
  конфигурацию и хранилище плагина.
- Маршруты настроек используют аутентификацию DSH.
- Любой разрешённый пользователь в группе может управлять вашими сессиями с
  их правами. Держите группу закрытой.

## Разработка

```sh
npm test                      # node --test, без зависимостей
node scripts/check-repo.mjs   # синтаксис, манифест, все тесты
```

Тесты используют поддельный Bot API и поддельные сервисы DSH; к Telegram и
настоящему DSH они не обращаются.

Прежний Go-мост для Codex App Server сохранён в ветке `archive/go-bridge` и
теге `v0.1.5`.
